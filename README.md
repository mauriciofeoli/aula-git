# Aula de Git

Este repositório foi criado para praticar os conceitos básicos de Git e GitHub em um projeto simples de página web.

## Objetivo

- aprender a versionar arquivos com Git;
- entender o fluxo de criação, alteração e commit;
- praticar a publicação de um projeto no GitHub;
- manter um repositório organizado com documentação básica.

## Estrutura do projeto

- `index.html` — estrutura principal da página;
- `styles.css` — estilos da página;
- `exemplo.txt` — arquivo de exemplo para testar alterações no repositório;
- `readme.md` — documentação inicial do projeto.

## Como abrir o projeto

1. abra o arquivo `index.html` em um navegador;
2. ou use um servidor local simples se preferir.

## Fluxo básico de Git

```bash
git init
git add .
git commit -m "Primeiro commit"
git status
git branch
git checkout -b nova-branch
```
